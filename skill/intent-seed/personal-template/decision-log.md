# Decision log

Each time the user decided against the assistant's stated view. Without this record, the pushback rule cannot be checked after a reset: the conversation is gone, and so is the evidence of who decided what and why.

This log is not for re-arguing old decisions. It is for learning, over time, where this user's judgment and the assistant's judgment tend to differ, and which one tends to hold up.

## Format

```
## YYYY-MM-DD · <short title>
- Decision: <what the user chose>
- Assistant's original view: <Y>
- Reason for Y: <evidence or reasoning at the time>
- What changed the outcome, if anything: <new information / change in what the user wants / none (user's call)>
- Outcome (fill in later): <what happened; what it teaches>
```

## Example (fictional; delete when you start)

```
## 2026-01-15 · Keep the long intro in the pitch deck
- Decision: keep the three-slide intro.
- Assistant's original view: cut it to one slide; the audience is short on time.
- Reason for Y: the event schedule gives each speaker ten minutes.
- What changed the outcome: none (user's call).
- Outcome: the intro landed well; this user knows this audience better than the schedule suggests.
```
